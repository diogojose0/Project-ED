# Project ED — Maze Game

Java maze game developed as a Data Structures project.

The project focuses on the implementation and use of custom data structures, graph-based maze representation and object-oriented design.

## Features

- Maze creation and loading
- Graph/network-based maze representation
- Custom data structures
- Turn-based gameplay
- Player movement
- Random corridor events
- Mini-games
- Replay system
- JSON persistence
- Unit tests

## Tech Stack

- Java
- Gradle
- JUnit
- JSON
- Custom collections and data structures

## Project Structure

```text
API-Project-ED/
├── src/main/java/
├── src/test/java/
├── files/
└── build.gradle
```

## Running the Project

```bash
cd API-Project-ED
gradlew.bat run
```

## Running Tests

```bash
gradlew.bat test
```
